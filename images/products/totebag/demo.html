What this is (and isn't)

This is a working prototype of the concept — real pacing, real photos, animated arrows and captions — so you can see if the idea works before anyone invests time in a polished final version. It is not a photoreal 360° product video; I don't have video-generation or 3D tools, so I built the closest thing I could with what's actually available: your real photos, sequenced and annotated.

To post this on Instagram

This page is HTML, not a video file — Instagram can't accept it directly, and I don't have a way to export it to .mp4 myself. The fastest fix (2 minutes, on your Mac): open QuickTime Player → File → New Screen Recording, select just this browser window, hit record, let the animation play through once, stop. That .mov file drops straight into Instagram (or convert it to .mp4 first with any free converter if Instagram asks for it).

How to get a fully polished version later

  • For true "bag turns around" rotation: film the actual bag on a simple turntable (a cheap rotating photo turntable, or even a lazy Susan) with a phone camera, or take ~8–12 photos spaced evenly around the bag and stitch them into a spin. This looks more authentic for a handmade brand than a CGI 3D render would.
  • For the sketch-arrow/handwriting style itself: VideoScribe is the tool built exactly for this ("someone is drawing it") — cheapest and fastest route. Canva has simpler animated templates with hand-drawn stickers if you want something free/quick. After Effects gives full control but has a real learning curve — worth it only if you'll make more than one of these.
  • Fastest realistic path: film the real bag being turned by hand + each feature being demonstrated (exactly like your existing product photos, but as video), then drop that footage into VideoScribe or Canva and add the arrows/captions over it.
  • Or hire it out: search "whiteboard animation" or "product explainer animation" on Fiverr/Upwork — this exact style is a common, inexpensive commission (often €50–150 for something this length).

If you get real turntable footage or a full set of angle photos, send them over — I can rebuild this prototype around them, or write you the exact VideoScribe/Canva project outline scene-by-scene.
