### Shared stock groups (added August 2026)
- Some products are sold as one item with several visual variants that are really drawn from a single, small combined batch (e.g. the Everyday Tote Bag: 4 colour/orientation variants, only 3 pieces exist in total). The Google Sheet's Stock tab can only track a limit *per id*, not a limit shared *across* several ids — so a true shared pool is enforced purely client-side, via `GHAR_STOCK_GROUPS` in cart.js and the `gharEffectiveRemaining(id)` helper (used everywhere `gharRemaining(id)` used to be checked before adding to cart: gharAdd, gharApplyStockToShop, gharProductModal's sold-out check, cart.html's qty+ button and cart-line "last pieces" label).
- If you add another multi-variant product with a shared pool, add an entry to `GHAR_STOCK_GROUPS` (ids array + limit) rather than inventing a new mechanism — and do NOT give the individual variant ids their own Stock-tab rows, since that would let the *sum* across variants exceed the real physical stock (each id's "sold" count is tracked independently by the Apps Script, with no awareness that the ids share a pool).

## Pricing & bulk (quantity) discounts (added August 2026)
- `GHAR_PRODUCTS[id].bulk = { extra: N }` marks a product where the first unit costs the normal `price`, and every unit after that costs a flat `extra` instead — a simple automatic "buy more, save" discount. `rectmat` and `circlemat` (Ikat table mats) have this: first mat €12.99, every extra mat €11.00 flat (so 3 mats = €12.99 + 11.00×2 = €34.99, saving €3.98 off buying 3 separately). `largecushion` (added August 2026) also uses it: first cover €32.99, every extra cover €28.00 flat (so 2 = €60.99). The 5 original block print cushions (marigold, rivervine, stone, forest, golden — added August 2026) also use it: first cover €26.99, every extra cover €24.00 flat (so 2 = €50.99).
- **Always compute a line/cart total through `gharLineTotal(id, qty)` in cart.js — never `price * qty` directly.** Both `gharCartTotal()` and cart.html's line-item renderer go through it; if you add a new price-affecting field, extend `gharLineTotal` rather than hand-rolling the math elsewhere. `gharUnitNote(id)` returns the "€X first, €Y each extra" string cart.html shows in place of the normal "€X each" for any `bulk` product.
- `gharBulkNote(id)` (added August 2026) returns a customer-facing "Buy more, save more — just €Y each after the first" string for any `bulk` product — the user explicitly wanted the savings called out somewhere visible, not just implied by the per-unit price. Rendered in two places: `shop.html`'s `gharCardHtml` (as `.product-bulk`, small terracotta text under the mini description) and `cart.js`'s `gharProductModal` (as `.pm-bulk`, right under the price). Both CSS classes are in styles.css near `.pm-price`. If a new `bulk` product is added, this note appears automatically — nothing else to wire up.
- Coasters and napkins do NOT use `bulk` — they were split into separate fixed-size SKUs instead, since their set sizes aren't a clean multiple of one unit (napkins: 4 vs 6; coasters: 2 vs 4): `coaster-set2` (€8.99, ~€4.50/coaster), `coaster-set4` (€12.99, ~€3.25/coaster — €4.99 cheaper than two Set-of-2s), `napkin-set4` (€24.99, ~€6.25/napkin), `napkin-set6` (€36.99, ~€6.17/napkin).
